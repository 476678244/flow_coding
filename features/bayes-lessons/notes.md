# notes · bayes-lessons

## 取舍

目标是认识世界的路径，不是多一本笔记本。路径写在技能里：开工先 `recall`，对话里重算，带出处的事实才 `note`，结论不回写。日志为空时多一段初始 investigate，仍然只调用 `note` 和 `recall`。不新增 `investigate` 命令，不新增调查报告或先验文件。

差异、是否打脸事先说出的旧信念、是否改变下一步，三道门槛都写进技能，命令行不打分。圆桌没有把其中一道收成唯一验收。2026-11-10 的决定是：空库可以继续是空的，不算欠一条模型总结的「这个项目是什么」。

2026-11-14 的纠正：三道门槛被用成「介绍里写过的身份不记」。投资知识库的第一批 `facts.jsonl` 因此只剩下文件分工、启用说明和第一次 recall 的日志，回答不了「这个仓库是什么」。身份改成必记，记仓库自己的句子。三道门槛只约束身份之外的新事实。`Soul.md` 没写这库是什么时，空库仍是诚实的。不要为了凑运行留下的行去记 recall 日志。

撤回是 `note` 的 `--retracts`，不是第三个命令。柜子、事件、哈希、合并、结论文件都不做。藏在门后等于以后会从侧门漏给代理，所以第一版里它们不存在。

工作目录叫 `.bayes_lessons`，在被打开的那个仓库根上。第一版里面只有 `meta.json` 和 `facts.jsonl`。新的一类数据以后加文件，不加第二个根目录。

`about` 用调用者的原话，精确匹配。不由程序自选类别。

证据只收仓库里已经存在的文件行。不代跑命令，避免技能变成任意执行入口。命令输出要记，先落成文件再记那一行。

推论门是词表：`因此` `这说明` `我认为` `应该` `概率`。这是机械门。人审时可以收紧或删掉「应该」——它会误伤「测试应该先红」这种观察句。

名字沿用点名的 `bayes-lessons`。这一版不计算先验和后验。名字承诺的贝叶斯更新，日志本身并不做。要改名，审这一份时改。
